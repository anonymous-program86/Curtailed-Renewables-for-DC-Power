# Energy intensity of AI inference

Fits throughput regressions using input and output token lengths, simulates traditional and test-time scaling workloads, and estimates IT electricity use per million output tokens. It also summarizes provincial PUE and uses it to estimate facility-level energy intensity.

## Inputs

A model-throughput workbook, hourly PUE simulation outputs, and the provincial boundary dataset and its attributes.

## Outputs

Annual PUE summaries and provincial electricity use per million output tokens.
