# Manuscript figures

Builds the provincial curtailment, utilization scenarios, installed capacity, inference energy intensity and sensitivity figures. It uses the original analysis inputs and also calculates the sensitivity ranges for national token potential.

## Inputs

Upstream analysis results, map geometry, data center coordinates, and the national daily energy series. The compact Excel files in data/ contain the available plotted values for reference.

## Outputs

Five manuscript figure groups when the upstream inputs are available. The daily series and map inputs are absent from this package.
